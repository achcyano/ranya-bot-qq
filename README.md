# 快速开始

1. 克隆本仓库到本地
2. 重命名`src/main/resources/application.yaml.template`文件为`application.yaml`
3. 在`server`下的`port`设置一个喜欢的端口
4. 安装[ NapCat ](https://napneko.github.io/guide/install)并使用`3`中配置的端口启动 **WebSocket客户端**
